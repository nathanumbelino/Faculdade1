Aprendendo Front-End

HTML

HTML é uma linguagem de marcação que permite organizar e estruturar textos, imagens, links e outros elementos em páginas da web, sendo interpretada por navegadores como Google Chrome, Firefox e Microsoft Edge . Diferente de linguagens de programação, HTML não cria algoritmos ou manipula dados; ele define a estrutura e a semântica do conteúdo

Conhecer o HTML

CSS

CSS é o mecanismo usado para aplicar estilos a documentos HTML, permitindo separar o conteúdo da apresentação visual. Ele controla aspectos como cores, tamanhos, posicionamento e responsividade.
